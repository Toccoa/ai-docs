# RAG 每日精进

一个面向 **AI Agent 架构师** 的 RAG 长期学习系统：每天 1–2 个知识点，按知识地图推进，自动插入前沿更新。

## 它怎么运转

- 每天 **09:00（Asia/Shanghai）**，自动化任务会在一个专用会话里生成当天内容。
- 任务会读取知识地图和进度，选择下 1–2 个未完成知识点。
- 生成前会检索最近的重要更新；有实质内容才写“前沿插入”，不硬凑。
- 生成后写入 `02-每日推荐/YYYY-MM-DD.md`，并更新进度与索引。
- 同一天重复触发不会重复生成；如果当天笔记已存在，只返回摘要。

## 文件说明

| 文件 | 用途 |
|---|---|
| `00-RAG知识地图.md` | 课程大纲：11 个模块、70+ 个原子知识点 |
| `01-学习进度.md` | 已完成、当前阶段、复习队列、统计 |
| `02-每日推荐/` | 每天一篇，按日期命名 |
| `03-模板.md` | 每日笔记模板（自动化任务按此生成） |
| `04-索引.md` | 所有期数的总索引 + 前沿资料库清单，方便回看 |
| `05-前沿资料/` | 与主线正交但足够系统的材料单独入库（每条标注主挂知识点） |
| `README.md` | 本说明 |

## 怎么用

1. **每天读 15–20 分钟**：先看“一句话结论”，再看“怎么做”和“坑”。
2. **做完 3 道自测**：把答案或疑问直接回复在会话里，第二天会带上复习提醒。
3. **每周日回看**：把本周的“一句话笔记”串起来，形成自己的架构判断。
4. **每月一次**：用 `M7 评估` 的知识，给自己的场景做一次归因。

## 怎么调整

- 改时间：在自动化任务列表中编辑这个任务的时间。
- 改节奏：在任务提示词里把“默认 2 个”改成 1 个，或改成“工作日 2 个、周末复习”。
- 改方向：直接编辑 `00-RAG知识地图.md`，增删知识点；ID 尽量保持稳定。
- 暂停：在任务列表中暂停，不会丢失进度。

## 设计原则

- **架构师视角**：不背概念，重点回答“为什么、什么时候用、代价是什么、怎么验证”。
- **证据优先**：区分事实、论文结论、个人建议；引用可核验来源。
- **先框架后细节**：先建立边界感和失败模型，再进入解析、切分、检索、评估。
- **前沿是插件**：新知识进入“前沿插入”或“动态新增区”，不打断主线。
