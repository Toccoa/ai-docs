# 前沿资料

值得单独拆开讲的论文与工程长文。**每篇都译成中文并加了精评**——精评的标准是：它值钱的地方、不能当真（或容易被误读）的地方、以及在什么条件下不该用它。

> **收录范围（2026-11-27 起）**：每日推荐的「今日前沿插入」里每一篇非中文来源，都会在这里有一份中文精读；同一主题的 2–3 篇会合并成一篇，避免碎片化。
> **原文存档策略**：能拿到完整原文的（ACL Anthology PDF、arXiv PDF 完整版）存在 `原文/pdf/`；arXiv 的 PDF 在本网络环境下会被限速截断，改为存 **HTML 版本**（`原文/html/`，优先全文 `-full.html`，退而求其次摘要页）；**每个条目的「原文」小节都给出可点击的本地链接**，拿不到存档的只留原文链接、不假装有。
> **这些附件会自动上线**：`scripts/publish.mjs` 会把与文章同级的 `原文/` 目录镜像到 `content/public/`，VitePress 再原样复制进站点，所以条目里的 `[PDF](原文/…)` 在 GitHub Pages 上点得开。

## 怎么用这一页

1. **先看你最近一期学的知识点**，从「按主题查」进对应条目；
2. 每条都给了「对你的动作」——那是可以直接排期的三到四条；
3. 条目里的「不能当真」段比「值钱」段更重要，尤其是当你要在评审会上引用时。

## 怎么往里加新条目

- 源文件放 `RAG 每日精进/05-前沿资料/`，命名 `YYYY-MM-DD-主题.md`
- 开头写定位块（主源 / 关联知识点 / 证据强度 / 本地存档状态）
- 正文至少含：一句话结论、方法要点（译）、关键数字、精评（值钱处 + 不能当真处）、对你的动作、自测
- 入库后跑 `node scripts/publish.mjs` 与 `node scripts/link-knowledge-map.mjs`，并把本页两张表各补一行
