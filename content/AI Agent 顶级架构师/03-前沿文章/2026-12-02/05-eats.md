## 为什么今天读这篇

因为它把"工具选择"这个通常靠提示词和工具描述解决的问题，换成了一个经验问题：同一套推理循环、同一个工具库，唯一差别是多了一个可检索的工具使用经验库，准确率就上去了。医学场景是它的压力测试场——神经工具的输出带有不确定性和个案差异，光看描述根本判断不出该用哪个。更值得架构师注意的是它的写入路径：不需要标注、不需要重训，用 LLM-as-a-Judge 给每次工具调用打一个 [−1,1] 的贡献分，再把整条轨迹连同查询嵌入写回库里。这让"越用越准"从一句口号变成了可以测的曲线（覆盖率 ρ 从 0 到 1，准确率单调上升）。最后，它的行为分析很实用：记忆并没有让模型"话变多"，而是让它在早期就压掉低价值工具、把高价值工具提前。

## 三句话摘要

1. 医学推理智能体里的神经工具（分类、诊断、报告生成等）输出不确定、且可靠性随病例变化，因此仅凭静态工具描述无法可靠地选择工具；EATS 用一个结构化的"经验记忆"来补这个缺口，记忆以查询嵌入为键、以带评分的工具使用事件为值。
2. 每次推理结束后，LLM-as-a-Judge 按五条准则（临床相关性、信息增量、诊断区分度、引用忠实度、答案一致性）给每个工具事件打一个 [−1,1] 的分，取五项算术平均；因为不依赖真值标注，记忆可以随测试时交互自然扩展。
3. 在 ChestAgentBench 上，EATS 相对无记忆的 MedRAX 基线在 Qwen3-VL 2B / 32B / GPT-5.5 上分别提升 +0.8 / +1.2 / +2.6 个点；随记忆覆盖率 ρ 从 0 到 1 准确率单调上升（64.0% → 65.2%），并在另外三个胸片基准上把总体准确率从 66.2% 提到 69.7%。

## 译文

## 摘要

医学推理智能体把大语言模型（LLM）的推理能力与临床工作流、专用神经工具结合起来。然而通用 LLM 对领域专用医学工具的训练暴露有限，而神经工具输出的不确定性与分布漂移，使得"从简单描述里选工具"比在计算器或查词典这类确定性场景中困难得多。本文提出 EATS，一种经验增强的工具选择策略，利用累积的工具使用轨迹来改善医学推理智能体中的工具选择。EATS 构建一个过去交互的记忆，包含查询、工具选择、参数与自评估反馈，并检索相关经验来指导新查询的工具选择。由于记忆构建不需要真值监督，EATS 能随测试时经验自然扩展。我们在工具增强的医学推理任务上评估 EATS，包括封闭式视觉问答与自由形式报告生成。在四个公开数据集 ChestAgentBench、CheXbench、MIMIC-CXR 与 SLAKE-VQA 上，跨三个多模态 LLM（Qwen3-VL 2B、Qwen3-VL 32B 与 GPT-5.5）的实验显示，工具选择行为与下游医学推理性能均取得一致提升。代码见 [https://github.com/Limingyuan001/EATS](https://github.com/Limingyuan001/EATS)。

## 1 引言

医学推理智能体把基于 LLM 的推理与临床工作流、专用神经工具整合起来，使感知、分析与决策能够在复杂诊断任务上协同完成。在实践中，这些智能体通过迭代的"计划–行动"循环运作，其中每个推理步骤都可能触发外部工具，以补充基础模型有限的参数知识。例如在医学影像诊断中，智能体可能调用神经网络完成分类、分割与报告生成等任务，从而扩展其感知与分析能力。然而，整合医学工具也带来额外挑战。与输出稳定可预测的确定性工具不同，医学模型往往并非在所有病例上都最优。这种变异降低了工具选择的可靠性，并使多步协调变得复杂。随着推理过程展开，早期引入的错误会传播到后续步骤，导致下游决策的误差累积。因此，在每个阶段选择合适的工具，始终是构建有效医学推理智能体的核心挑战。

*图 1：用工具使用经验来做工具选择的示意。* 没有工具使用参考（例如工具可靠性与病例相似度）时，ReAct 风格智能体选择 T-VQA 并给出错误答案。若从相似的历史病例中检索到工具可靠性信息，它选择 T-DGN 并给出正确答案。

当前医学推理智能体中的工具选择策略，通常把用户查询与强调预定义功能或能力的工具描述相匹配，这限制了它们纳入患者特定上下文的能力。这种范式对通用智能体系统里计算器、搜索引擎这类确定性工具有效，但对神经工具表现出输出不确定性与个案差异的医学场景就不那么合适。近期工作探索用重训练方法改善工具选择，但其在临床领域的可扩展性受制于数据异质性、隐私限制以及商业 LLM 的黑箱性质。相比之下，相似或相关病例可以作为工具选择的经验参考。它们把当前患者上下文与先前的工具使用结果连起来，让在可比病例上表现良好的工具被优先选中，而不那么可靠的则被避开。这种基于病例的落地方式还有助于识别跨步骤反复出现的失败模式，从而减少多阶段推理中的误差累积，支撑更具自适应性与上下文感知的工具选择。如图 1 所示，没有工具使用经验时，智能体选了一个看似合理但不合适的工具，给出错误诊断；而有了两个相似病例的工具使用经验，智能体识别出更可靠的工具有了正确诊断。

本文提出 EATS，一种经验增强的工具选择策略，利用累积的工具使用轨迹改善医学推理智能体。EATS 构建一个过去交互的记忆，包含查询、工具选择、输入参数、工具输出与自评估反馈。智能体随后检索相关经验，把它们作为工具使用参考来指导新查询的工具选择。这些被检索到的经验被注入推理上下文，使可靠的工具选择无需额外训练或重训模型即可实现。每个病例结束后，一个 LLM-as-a-Judge 模块评估已完成的工具使用轨迹，按两个维度上的多条准则给各个工具使用事件打分，包括临床相关性、信息增量、诊断区分度、引用忠实度与答案一致性。更新后的经验随后被存入记忆供未来检索。由于记忆构建不依赖真值监督，EATS 可以随测试时交互与累积经验持续扩展。

我们在四个胸片基准上评估所提方法：ChestAgentBench、CheXbench、MIMIC-CXR 与 SLAKE-VQA，使用三个多模态基础模型（Qwen3-VL 2B、Qwen3-VL 32B 与 GPT-5.5）。该方法在小型与大型 Qwen3-VL 模型以及前沿模型 GPT-5.5 上都一致优于 MedRAX 基线（无记忆），且增益随工具使用经验累积而增大。该方法还泛化到另外三个覆盖报告生成与封闭式 VQA 的推理基准。进一步分析显示，性能提升主要来自更好的工具选择决策——用哪个工具、何时用、以及如何设置其参数——而不是输入或输出多样性的增加。

## 2 相关工作

**医学推理智能体。** 医学 AI 已从微调静态的语言与视觉语言模型，演进为动态调用外部工具进行多步临床推理的基于智能体的系统。早期模型在临床问答上表现不错，但始终是被动的，缺乏在推理中主动协调工具使用的能力。近期工作引入带显式规划与工具调用的工具增强智能体，包括多角色 LLM 集成、面向多模态工具使用的指令微调统一模型、面向影像任务的扩展工具库，以及基于检索的工作流规划或罕见病推理。尽管有这些进展，现有方法并未显式支持从累积的工具使用经验中自我改进，而且通常需要重训练或外部监督才能随时间提升。

**工具使用与记忆。** 通用智能体系统已经探索了多种工具使用路径。Toolformer 让工具调用决策可自监督学习，而 ReAct 把推理轨迹与工具动作整合进统一的交互循环。更结构化的方法包括层级化工具组织、基于效用的工具调用剪枝，以及面向工具选择策略的强化学习。工具使用评估的基准也已被提出。然而这些方法主要面向能力定义良好且静态的工具，而医学神经工具表现出随病例变化的可靠性，无法仅从描述推断，现有方法在不重训练的前提下无法处理这一点。并行地，外部记忆被广泛用于增强智能体推理。现有记忆机制包括存储跨任务持久知识的长期记忆，以及记录输入、中间推理、工具调用与输出这类上下文内信息的短期记忆。若干方法存储并精炼智能体经验，包括言语自我反思、情景式工具使用记忆，以及跨短期与长期存储的统一记忆管理。一些研究进一步用记忆支撑基于强化学习的微调，改善工具选择策略，但需要重训练、且未在推理时直接利用记忆。

## 3 方法

本节先形式化医学推理智能体，并给出所提 EATS 策略的总览；随后详述关键组件，包括记忆构建、工具选择与记忆更新。

### 3.1 问题形式化

我们考虑一个用于胸片解读的 ReAct 风格智能体，配备 K 个专用神经工具 𝒯 = {T_1, …, T_K}。每个输入是一个临床病例 𝒳 = {I, Q}，由胸片图像 I 与临床问题 Q 组成。多模态基础模型 f_θ 充当智能体的推理核心，条件于一个系统提示 P_syst，其中定义了工具描述与使用说明。在每一步 l ∈ {1, …, L}，智能体生成一条推理消息 C_l 并选择一个工具子集 𝒯_l ⊆ 𝒯 来产生反馈 E_l：

> C_l, 𝒯_l = f_θ( 𝒳, C_{<l}, E_{<l}; P_syst ),　(1)
> E_l = { T(𝒳, C_l) | T ∈ 𝒯_l },　(2)

其中 C_{<l} 与 E_{<l} 表示此前的推理与工具输出。当 𝒯_l = ∅ 时过程终止，最终预测为 ŷ = C_L。与计算器、搜索引擎这类确定性工具不同，医学神经工具（例如 LLaVA-Med、CheXagent）表现出随病例变化的行为，且可靠性因输入而异。因此，从三元组（𝒳、C_{<l}、E_{<l}）到合适工具选择 𝒯_l 的映射，无法仅靠 P_syst 中的静态工具描述可靠捕获。

*图 2：所提 EATS 总览。*（上）工具选择：智能体从记忆 ℳ 中检索相似的历史条目，组装出工具可靠性参考 Γ(𝒳) 作为额外上下文，并迭代进行推理与工具选择，直到 𝒯_l = ∅。（下）记忆更新：已完成的轨迹按五条准则评估、给每个工具事件打分，得到的工具使用经验 𝒰 被写回 ℳ 供未来检索。（左）一个代表性胸片病例。

如图 2 所示，我们为医学推理智能体提出如下经验增强的工具选择策略。给定新病例 𝒳，智能体从记忆 ℳ 中检索相似历史病例，把它们的工具可靠性参考 Γ(𝒳) 纳入基础模型上下文，以支撑可靠性感知的决策。推理结束后，评估每个工具调用对该病例的贡献，并把得到的经验作为新的工具使用记录 𝒰 连同病例表示 𝐳 一起存入记忆，供未来检索。以下各节详述每个组件。

### 3.2 经验记忆

该策略的第一个组件是一个结构化经验记忆，以可检索的形式存储历史病例及其关联的工具使用经验。记忆并不只保留原始查询或最终预测，而是保存与未来工具选择最相关的信息，包括检索查询嵌入、被调用的工具及其有效性分数。形式上，记忆组织为一个键值存储：

> ℳ = { (𝐳_n, 𝒰_n) }_{n=1}^{|ℳ|}，　(3)

其中 𝐳_n ∈ ℝ^{384} 是第 n 个病例 𝒳_n =（I_n, Q_n）的嵌入键，在工具选择阶段计算。对应的值 𝒰_n =（u_{n,1}, …, u_{n,J_n}）存储从已完成推理轨迹中收集的 J_n 个工具事件。每个事件定义为

> u_{n,j} = ( T_{n,j}, a_{n,j}, s_{n,j} )。　(4)

其中 T_{n,j} ∈ 𝒯 表示被调用的工具，a_{n,j} 是其输入参数（例如 LLaVA-Med 风格工具的提示），s_{n,j} ∈ [−1, 1] 是一个标量分数，衡量该次工具调用对解决病例 n 的效用。这个分数作为存在记忆中的监督信号，供未来检索与决策使用。s_{n,j} 的估计在 3.4 节描述。

### 3.3 工具选择

推理时，智能体处理新病例 𝒳 = {I, Q}，利用从经验记忆检索到的历史工具使用经验。我们首先从 Q 中抽取结构化语义标签，并编码为查询向量：

> 𝐳 = ϕ(𝐜) ∈ ℝ^{384}，　𝐜 = f_θ(Q; P_ext)，　(5)

其中 P_ext 是用于标签抽取的提示（见附录 H），𝐜 包含六类结构化标签，ϕ(·) 是一个文本嵌入模型。对每个记忆条目 (𝐳_n, 𝒰_n) ∈ ℳ，我们计算相似度分数

> r_n = cos(𝐳, 𝐳_n)，　n ∈ {1, …, |ℳ|}，　(6)

它衡量当前病例与历史病例之间的语义相似度。随后我们构造检索集：选取相似度高于阈值 τ 的条目，并保留得分最高的至多 k 个：

> ℛ_{τ,k}(𝒳; ℳ) ⊆ { n | r_n ≥ τ }，　(7)
> |ℛ_{τ,k}(𝒳; ℳ)| ≤ k，　(8)

其中条目按 r_n 降序排列、只保留前 k 个，τ 是相似度阈值，k 是最大检索条目数。若没有历史条目满足阈值，则 ℛ_{τ,k}(𝒳; ℳ) = ∅，智能体退化为无记忆支撑的纯提示驱动推理。对每个被检索到的索引 n ∈ ℛ_{τ,k}(𝒳; ℳ)，对应的工具使用经验 𝒰_n 与相似度分数 r_n 被组装成工具可靠性参考：

> Γ(𝒳) = { (r_n, 𝒰_n) | n ∈ ℛ_{τ,k}(𝒳; ℳ) }，　(9)

它概括了相似病例中工具的行为及其有效性。以当前病例、推理历史与 Γ(𝒳) 为条件，智能体进行迭代式的经验增强推理。在每一步 l ∈ {1, …, L}：

> C_l, 𝒯_l = f_θ( 𝒳, C_{<l}, E_{<l}, Γ(𝒳); P_syst )，　(10)
> E_l = { T(𝒳, C_l) | T ∈ 𝒯_l }。　(11)

当 𝒯_l = ∅ 或达到最多 L = 7 步时过程终止，最后的推理输出被当作预测 ŷ。

### 3.4 记忆更新

**评估。** 如图 2（下）所示，我们用一个不需要真值标签的、基于过程的协议来评估已完成轨迹中的每个工具事件（与基于真值的判官的对比见附录 D）。在 P_eval 引导下，同一个基础模型 f_θ 用 LLM-as-a-Judge 按五条准则给每个事件打分，这些准则同时评估输出质量与它在推理过程中的作用。五条准则是：（1）临床相关性，工具输出是否针对相关病理或任务；（2）信息增量，它是否提供了输入问题之外的信息；（3）诊断区分度，它是否有助于在竞争性诊断之间区分；（4）引用忠实度，推理是否正确使用或引用了工具输出；（5）答案一致性，输出是否与最终预测一致。前三条主要评估工具输出的内在质量，后两条评估它被整合进推理过程的连贯程度。每条准则独立按五点量表打分并映射到 [−1, 1]；完整评分细则与提示模板 P_eval 见附录 I。对每个工具事件 j ∈ {1, …, J}，贡献分定义为：

> s_j = M( f_θ( 𝒳, C_{<L}, E_{<L}, ŷ; P_eval ) ) ∈ [−1, 1]，　(12)

其中 M(·) 表示计算五条准则分数算术平均的算子。

**更新。** 经验记忆用新收集的工具使用经验与对应查询嵌入更新，供未来检索。具体地，一个病例中全部 J 个工具事件打分完毕后，我们把工具使用经验构造成元组集合 𝒰 = {(T_j, a_j, s_j)}_{j=1}^{J}。推理期间算出的查询嵌入 𝐳 被复用为记忆存储的键。得到的键值对 (𝐳, 𝒰) 随后被追加进记忆：

> ℳ ← ℳ ∪ { (𝐳, 𝒰) }。　(13)

这样，每个被处理的病例都用评估过的工具使用经验丰富记忆，支撑未来病例中更可靠的工具选择与证据整合。

## 4 实验

本节研究三个问题：（i）所提记忆能否在基础模型尺度与胸片任务上提升准确率；（ii）性能是否随累积的工具使用经验而扩展；（iii）工具使用行为的变化如何转化为准确率增益。为隔离记忆的作用，我们的策略与 MedRAX 共享同一推理循环与工具库；唯一差别是注入推理过程的记忆增强上下文 Γ(𝒳)，以及用于记忆更新的、事后的工具贡献打分。因此我们采用无记忆的 MedRAX 智能体作为比较基线，并在胸片解读上用既有神经工具评估。

### 4.1 实验设置

**数据集。** 我们在 MedRAX 采用的四个胸片基准上评估，它们覆盖临床推理的互补侧面：

- **ChestAgentBench**：一个综合的胸片推理基准，含 2,500 个六选一问题，覆盖七项能力——检测、分类、定位、比较、关系、表征与诊断。性能以总体与分项准确率衡量。
- **CheXbench**：我们使用视觉问答子集（来自 Rad-Restruct 与 SLAKE 的 238 个问题）与细粒度图文推理子集（来自 OpenI 的 380 个问题），因为它们最贴近需要精确区分相似发现的复杂临床工作流。我们报告每个子集与总体均值上的准确率。
- **MIMIC-CXR**：在 MIMIC-CXR 测试集的 3,858 张单图胸片上做放射报告生成。遵循 M4CXR，我们报告 14 个医学观察标签（mF1-14、MF1-14；CheXpert 标签，由 CheXbert 抽取）与 5 个关键发现（mF1-5、MF1-5；心脏增大、水肿、实变、肺不张与胸腔积液，由 CheXbert 抽取）上的微观与宏观平均 F1。
- **SLAKE-VQA**：遵循 M4CXR，在从 SLAKE 测试集过滤出的 114 个封闭式英文胸片样本上做医学视觉问答。我们报告精确匹配准确率与召回率（生成回答中包含的真值词比例）。

**设置。** 为在 ChestAgentBench 上考察策略的自我改进能力，我们设计了两种构建工具使用经验记忆的设置：测试时设置与预构建设置。在测试时设置中，数据集被顺序处理并配以动态记忆：每个病例先针对现有记忆推理，然后其工具使用经验被打分并写回记忆。我们进一步用记忆覆盖率 ρ ∈ [0, 1] 参数化该设置：数据集前 ρ·N 个病例用动态记忆更新处理（读后写），其余 (1−ρ)·N 个病例针对由此得到的固定记忆处理（只读）；于是 ρ = 0 复现基线智能体 MedRAX，ρ = 1 对应每个病例都贡献记忆的完整测试时设置。在预构建设置中，推理使用一个固定的、预先构建好的记忆；为受控比较，我们采用 5 折交叉验证，用四折填充记忆、留出剩余一折用于评估。

**词表熵。** 作为对照，提示与回答在单次调用级与语料级的词级香农熵变化大多集中在 0.10 bit 以下，主要例外是语料级的 Dgn 回答。这说明记忆并非主要通过增加啰嗦程度或词汇多样性来提升性能（见附录 J）。附录 F 进一步提供定性示例，展示记忆可以改变工具参数，例如把提示聚焦到临床相关线索上，或为多视角比较而修正图像输入。

**小结。** 上述视角收敛到一句简洁的陈述：*记忆对工具使用的作用可以归结为可靠性感知的工具选择。* 以从相似历史病例检索到的经验证据为条件，智能体（i）避免那些先前经验标记为对当前病例不太可能有帮助的调用——降低冗余工具的频率，同时提高存活调用的单次有用性；并且（ii）把最可靠的工具提前到轨迹更早处，用工具内深化替换与病例无关的跨工具验证。两种效应共享同一底层机制——用病例特定的可靠性证据替换仅凭提示的工具仲裁——并共同产生 4.2 节报告的准确率增益。

## 5 结论

我们提出 EATS，一种用于改善医学推理智能体中工具选择的经验增强策略。通过构建工具使用轨迹的长期记忆并在推理时检索相关的历史经验，EATS 在没有额外训练或监督的情况下实现了可靠性感知的决策。这一设计有效应对了临床工作流中神经工具输出不确定且随病例变化的难题。跨四个基准、三个多模态基础模型的广泛实验显示，工具选择准确率与下游推理任务（包括 VQA 与报告生成）都取得一致改善。这些结果凸显了利用累积经验来实现可扩展、自适应的医学工具使用的价值。

## 与路线图的挂接

- **A3-05（记忆冲突与一致性）**：EATS 的记忆是"经验型"的，因此它的冲突形态与事实型记忆不同：不是新旧值互相矛盾，而是同一工具在不同病例上的可靠性分数互相矛盾。它的处理办法是双重的——写入侧用五条准则把一次调用压成一个标量分数（把多维质量降成一维可靠度），读取侧用相似度阈值 τ 加 top-k 来保证只有可比病例参与裁决（k 从 3 增到 10 反而掉 0.9 个点，就是"稀释"的实证）。这对设计的启示是：经验记忆的一致性靠"可比性"维持，而不是靠更强的判官。
- **A4-06（工具调用的审计与可观测）**：文中"每个工具事件存下工具名、参数、分数"正是一份最小审计记录：它能回答"这次为什么选了这个工具""这个工具在这个病例上值多少分"，并且因为分数是可解释的五项均值，出问题时可以定位到具体哪一条准则。需要注意的是它的判官与作答是同一个模型（f_θ），这在审计上是自证——对高风控场景，判官应当换一个独立模型，否则"自评估反馈"会继承作答模型的偏好。
