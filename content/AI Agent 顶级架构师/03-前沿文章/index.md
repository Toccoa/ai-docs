# 前沿文章库

每天收录 5 篇与 Agent 架构直接相关的业界文章，**原文与中文译文同时落本地**。原文用于核对与引用，译文用于快速读。

选择口径（按优先级）：

1. **48 小时内**发布的工程实践、架构复盘、官方工程博客；
2. **一周内**的重要论文或权威机构文章；
3. 都不够时，补录**此前未收录过的**奠基性材料，标题注明「补录」，并在正文说明理由。

每篇都标注**挂接知识点**，学到对应位置时可以回读。不做「日报式罗列」——只收能改变你架构决策的东西。

## 收录原则

- **原文可核**：每篇保留原文链接与本地原文，译文里的数字都能回到原文对照。
- **不堆量**：宁可选 3 篇真正有用的，不凑 5 篇标题。
- **标注翻译方式**：全文翻译 / 精译，精译要写明略去了什么。
- **挂接知识点**：文章不是孤立的，它必须回答「学到哪一步时该读它」。
