# RAG 知识地图（AI Agent 架构师版）

> 目标：不是“知道 RAG 是什么”，而是能在真实约束下完成 **选型 → 设计 → 评估 → 上线 → 运营**。
>
> 使用方式：按模块顺序推进；每个知识点 15–25 分钟。地图只定义“学什么”，每日推荐负责“怎么学”。
>
> 版本：v1.0 ｜ 建立于 2026-11-09

## 图例

- 难度：`入门` / `进阶` / `高级`
- 学习顺序：先 M0 建立框架，再 M1–M2 打地基，然后 M3–M5 主线，M6 进阶，M7–M8 工程化，M9 产品化，M10 持续跟踪。
- “完成”状态记录在 `01-学习进度.md`，不在本文件反复勾选，避免地图被改乱。

## 建议的 8 周主线

| 周 | 重点 | 产出 |
|---|---|---|
| 第 1 周 | M0 + M1 | 画出自己场景的证据链与解析方案 |
| 第 2 周 | M2 + M3 前半 | 做一次切分 / 混合检索对比实验 |
| 第 3 周 | M3 后半 + M4 | 加 rerank，建立检索指标基线 |
| 第 4 周 | M5 | 上下文组装与引用 / 拒答方案 |
| 第 5 周 | M6 | 选一个高级架构做小 PoC（GraphRAG 或 Agentic RAG） |
| 第 6 周 | M7 | 建 50–100 条黄金集，完成端到端归因 |
| 第 7 周 | M8 | 补可观测性、权限、缓存、灰度 |
| 第 8 周 | M9 + M10 | 写一页 ROI / 架构决策记录，建立前沿雷达 |

| 日期 | 来源 | 新知识点 | 处理状态 |

| 2026-11-10 | Anthropic Engineering《The components of agent memory》（Lance Martin，2026-11-06） | **记忆四层栈与离线整理（dreaming）**：transcript / notes / wiki / injected context 四层物理隔离 + 离线纠错、建表征、晋升、聚焦、补漏。核心判据：① 更强的模型从记忆获得的**增益更小**（必须同报 baseline）；② **硬规则（如"只记失败"）是负收益**，Opus 5 −0.234；③ 抽象层值得建**当且仅当"跨文档综合"是主要成本**；④ 纯 search 基线**恒定不涨**（53%），只有写回+综合才随时间变好；⑤ 多 agent 同写一页 72% → 一页一 writer + 逐字引用 100%。见 [`05-前沿资料/2026-11-10-记忆栈-四层与dreaming.md`](05-前沿资料/2026-11-10-记忆栈-四层与dreaming.md) | **已入库**（2026-11-10），主挂 R6-09，交叉 R6-08 / R10-05；建议在学 R6-09 时精读，学 R6-08 时重读第六、八节 |

## 维护规则

1. 不轻易改 ID；已推荐的 ID 保持稳定，便于进度与索引引用。
2. 新知识点优先追加到对应模块末尾；跨模块的放“动态新增区”，观察 1–2 周后再归位。
3. 每完成一个模块，回看一次地图：删掉已过时的点，补上实践中遇到的缺口。
4. 地图是“课程大纲”，不是“论文综述”；每个点必须能落到一个设计动作或评估动作。
