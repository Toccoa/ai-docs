# 每日 AI Agent 技术精选

按天归档的 AI Agent 技术情报。**一天一个目录**，当天的日报、深度精讲、原文翻译放在一起，一次读完。

## 目录怎么读

```
2026-11-10/
├── AI-Agent-开发日报-2026-11-10        ← 当天值得读的发布与讨论
├── 深度精讲-LangChain-…                ← 拆成方法论的中文解读
├── 原文翻译-LangChain-…                ← 保留原始论证的全文翻译
└── 异步任务Agent-…-知识地图-2026-11-10  ← 当天话题的结构化框架
```

左侧目录按日期从新到旧排，展开某一天就能看到当天全部文章。同一天里固定按「日报 → 精讲 → 翻译 → 知识地图」的顺序。

## 每篇大概长什么样

- **开发日报**：几条当天动态，每条一句"为什么值得读"。
- **深度精讲**：把论文 / 工程博客拆成"该怎么做"，给结论而不是复述原文。
- **原文翻译**：中文全文，保留论证链条，适合回查细节。
- **知识地图**：把当天的话题画成结构化框架，用来对照自己理解到哪一层。
