# 前沿文章库

每天收录 5 篇与 Agent 效果评测直接相关的业界新文章，**原文与中文译文同时落本地**。原文用于核对与引用，译文用于快速读。

选择口径（按优先级）：

1. **48 小时内**发布的工程实践、基准论文、评测方法论文；
2. 一周内的重要论文或官方工程博客；
3. 都不是时，补录**此前未收录过的**经典材料，并在标题注明「补录」。

每篇都会标注**挂接知识点**，学到对应位置时可以回读。不做「日报式罗列」——只收能改变你做评测方式的东西。

## 收录原则

- **原文可核**：每篇都保留原文链接与本地原文，译文里的数字都能回到原文对照。
- **不堆量**：宁可选 3 篇真正有用的，不凑 5 篇标题。
- **标注翻译方式**：全文翻译 / 精译，以及精译略去了什么。
- **挂接知识点**：文章不是孤立的，它必须回答「学到哪一步时该读它」。
