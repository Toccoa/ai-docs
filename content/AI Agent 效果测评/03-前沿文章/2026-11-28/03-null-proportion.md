## 为什么今天读这篇

绝大多数 Agent 评测都偷偷依赖一个前提：**存在一个外部的、可核对的金标准标签**——证明对不对、代码能不能编译过单测、SWE-bench 的隐藏测试过没过。但只要 Agent 被赋予端到端自主权（提出干预、跑实验、决定下一步上线什么、下一步查什么），"这一步做对了没有"就再也观测不到，只能从噪声很大、经常给不出结论的实验里**推断**。这篇文章把"Agent 质量"定义成轨迹上正确决策的加权和，用 **e 值**（e-value）序列替代标准答案作为正确性的统计证据，并给出在**任意依赖、数据驱动停时、动态生成假设**下都成立的上下界估计量与置信集。它的价值不在于又一套指标，而在于**把"决策对不对"变成了带频率派保证的区间**——这正是"可靠性评测"目前最大的方法缺口。

## 三句话摘要

1. 把 Agent 质量定义为 $\theta_* = \sum_{i=1}^{M} c_i\theta_i$（$M$ 条决策、$c_i$ 可依赖整条观测轨迹），正确性标签 $\theta_i$ 从不被观测，只用 e 值对 $(\theta_i=1)$ 与 $(\theta_i=0)$ 两个假设各自累积证据。
2. 用可预测权重 $(w_{i,t},\bar{w}_{i,t})$ 构造上界估计量 $\hat{\theta}_*^{U}=\sum_i\max(c_i-A_i,-\bar{A}_i)$，**对所有 $Q\in\mathcal{Q}$ 一致有效**（定理 1）；且该估计量类**逐实例可逼近锐界** $U(\tilde{Q})$（定理 2），一致性不以牺牲锐度为代价；在固定 $M$ 的简化设定下，取 $w_i=\lambda/(M(1-\lambda))$ 即路径上不劣于 Storey 估计量（引理 1）。
3. 用"共享资金的序贯下注"（假设 6）得到置信集 $C(\alpha,F_N)$，其中 $K_N(v)<1/\alpha$ 构成合法 e 值（定理 3）；NetworkX 案例中，在 5% 最小加速阈值下 Opus 的下界估计约 **0.15**，而 Haiku 的上界估计为 **0.11**，$p$ 增大时差距持续存在。

## 译文

### 摘要

Agent 所采取动作的正确性，通常是对照**已知的、经外部核验的标准答案标签**来评估的，例如证明是否正确、代码是否能编译并通过单元测试。然而，当编码 Agent 与科学 Agent 被赋予更多端到端自主权——提出干预、运行实验、决定接下来部署什么、调查什么——一个 Agent 的动作是否**真正**改善了某个结果，就必须从带噪声、且往往得不出结论的实验中推断。为在此设定下评估 Agent，我们把**Agent 质量**定义为沿其轨迹的正确决策的加权和，并用 **e 值**（e-value）序列作为关于正确性的统计证据，替代标准答案标签。我们的框架容纳任意依赖的决策、数据依赖的轨迹终止、动态生成的假设，以及仅在轨迹结束后才定义的质量度量。我们为 Agent 质量构造上界与下界估计量以及置信集，其统计保证在 Agent 轨迹分布上**一致成立**，并证明我们估计量类的**逐实例锐度**（instance-wise sharpness）。我们用一个案例研究演示这些方法：比较 Claude Opus 与 Claude Haiku 在改善一个开源 Python 包运行时性能上的成功程度。

### 1 引言

近年来，Agent 式 AI 已在真实系统中大量出现。编码 Agent 例行地对生产软件与基础设施提出改动，这些改动随后被部署到用户群体中（Alshahwan et al. 2024，Novikov et al. 2025）。多 Agent 系统被用来生成科学假设（Gottweis et al. 2026，Xie et al. 2026），这些假设随后在真实世界实验中被检验。当 Agent 被授予自主决策权时，一项基础任务就是**对 Agent 决策质量的可靠评估**。

基准测试仍是衡量 Agent 质量的事实标准，但这些方法在评估 Agent **部署期间**所做决策时力不从心。设想一个自主编码 Agent 更新用户界面，目标是提升平均用户参与度。一个把用户参与度相对基线提升了的改动，被认为是正确的。在传统基于软件的基准中，如 SWE-Bench（Jimenez et al. 2024），每个决策都可以用单元测试或参考答案标为正确或错误。但对我们的编码 Agent 而言，它的改动是否**真的**提升了平均用户参与度是未知的：这等价于一个关于系统未知分布的陈述。虽然可以收集数据来检验这一断言，但**整个用户群体上**用户参与度的期望提升从未被直接观测到。本文聚焦的正是这一设定：正确性从不被观测，只有带噪声的测量可作为支持或反对某决策正确性的证据。

为处理未知的决策质量，流行做法是使用**估计出来的正确性标签**，来源可以是统计方法，也可以是另一个 Agent。常见的启发式包括 LLM-as-judge 框架，即用另一个模型作为 Agent 决策的裁判（Zheng et al. 2023）。另一类框架用一小批带正确性标签的决策来构造估计标签（Wang et al. 2020，Angelopoulos et al. 2023）。但在我们的设定下，这两类做法都**无法给出带统计保证的可靠评估**。LLM 填补的标签容易出现显著偏差与无效的置信区间，即使估计标签的准确率相对较高也是如此（Egami et al. 2023）。而像预测驱动推断（prediction-powered inference）这样的统计框架虽能构造无偏的正确性估计（Boyeau et al. 2025），却要求至少观测到**少量**真实标签，因而无法刻画我们"零观测标签"的设定。

本文把 Agent 评测问题重新表述为一个**多重假设检验**问题：每个决策都关联一组关于该决策正确性的假设。例如在软件部署设定中，每个决策关联一对假设，分别声称该改动提升了或降低了用户参与度，而"正确的改动"被定义为提升了期望参与度的改动。Agent 质量于是定义为正确决策的加权和，例如 Agent 的改动中改善了参与度的比例。我们的框架对应于把 Agent 的决策评估为**零假设计数**的加权和，建立在零假设比例估计（null proportion estimation）之上（Storey 2002，Meinshausen and Rice 2006，Efron 2008）。

与既有工作不同，我们针对 Agent 应用在实践中的三个关键特征来设计方法。

**第一，Agent 是自适应行动的**：每个决策都是对更早决策结果的响应，系统也随之变化。因此，决策之间、以及关于其质量的证据之间，可能是**任意依赖**的。

**第二，Agent 应用常被持续监控，并可能在任意数据依赖的时刻被终止**。例如，当收集到的关于该 Agent 的数据显示有害行为时，它通常会被相应地终止。

**第三，质量可能只在轨迹结束后才被定义**；例如"改善型改动的比例"取决于 Agent 是否选择采纳某个改动，以及总共提出了多少改动。经典的零假设估计设定假定假设集合固定、p 值在固定时刻可得。但在 Agent 应用中，改动数量可能是随机的，而且经典 p 值在数据驱动停时下往往**失效**。

我们的证据原语是 **e 值**（Vovk and Wang 2021，Grünwald et al. 2024，Ramdas et al. 2023a）。对每个决策，我们使用两条 e 值序列，在部署过程中检验该 Agent 决策的正确性。与 p 值不同，e 值在**可选停时**下仍然有效，且可以在**任意依赖**下合并，这正好提供了 Agent 评测所需的灵活性。它们也不难获得：基于 e 值的 anytime-valid 检验早已被用于软件发布门禁与工业实验监控（Lindon et al. 2022，Johari et al. 2022）。

我们的贡献如下。

1. **框架**。我们把 Agent 质量形式化为沿自适应生成的轨迹上、未观测正确性指示变量的**数据依赖加权和**。我们的模型允许决策数量、轨迹长度以及 Agent 质量的定义本身都是随机且数据依赖的。

2. **估计**。我们构造基于 e 值的上界与下界估计量，它们在部署轨迹上**一致有效**。我们的估计量类包含对任意实例都近似锐的估计量。在简化设定下，我们证明本方法**优于**（dominates）Storey 估计量（Storey 2002）。

3. **推断**。我们为 Agent 质量构造置信集，在轨迹部署上提供**一致覆盖**。我们把该估计量类与 e 值合并（e-value merging）联系起来，并讨论随机假设对置信集构造的影响。

4. **真实世界研究**。为检验我们的估计量类与置信集，我们基于轨迹模拟构造了带可预测调参启发式的估计量与置信区间。我们以开源 NetworkX Python 包（Hagberg et al. 2008）上的代码改进为案例，演示方法的实际应用。

第 2 节形式化 Agent 评测与识别问题；第 3、4 节分别发展估计量与置信区间；第 5 节给出真实世界案例研究。关于相关工作、证明、调参流程与实验设置的进一步讨论见补充材料。

### 2 设定与估计目标

Agent 在离散时间 $t\in\mathbb{N}$ 上从系统中**序贯地**收集信息。它可以在任意时刻基于迄今观测到的信息做出决策。轨迹在可能是数据驱动的时刻 $N$ 结束，到轨迹结束时共做出 $M$ 个决策。

我们要评估的是 Agent 沿这条轨迹的**决策序列的质量**。Agent 做决策时，诱导出一个随机的二元正确性标签序列 $(\theta_1,\dots,\theta_M)$，其中 $\theta_i=1$ 表示该决策是正确的。我们把 Agent 质量 $\theta_*$ 定义为轨迹上决策正确性的加权和：

$$\theta_*=\sum_{i=1}^{M}c_i\theta_i,$$

其中 $c_i$ 是数据驱动的权重，可以依赖于我们观测到的整条轨迹。$c_i$ 的简单取法如 $c_i=1$ 或 $c_i=1/M$，分别把 $\theta_*$ 定义成**正确改动的数量**或**比例**。下面给出一个真实世界的 $\theta_*$ 例子。

**例 1（带在线实验的编码 Agent）。** 考虑一个把软件改动推送到真实系统的编码 Agent。令 $P_i$ 表示在 Agent 第 $i$ 个代码改动之后，结果指标 $(X_{\text{goal} },X_{\text{guard} })$ 上的分布，例如用户参与度与系统崩溃率。若 Agent 选择**采纳**改动 $i$（例如基于一个从 $P_i$ 采样的实验），令 $c_i=1$；若该改动被回退，则 $c_i=0$，并令 $j_i=\sup\{j\in\mathbb{N}_0: j<i,\ c_j=1\}$。把"正确"定义为：该改动使平均目标指标**至少提升 10%**，且不使守卫指标恶化：

$$\theta_i=\mathbf{1}\left\{\mathbb{E}_{P_i}[X_{\text{goal} }]/\mathbb{E}_{P_{j_i} }[X_{\text{goal} }]\ge 1.1\ \wedge\ \mathbb{E}_{P_i}[X_{\text{guard} }]\le\mathbb{E}_{P_{j_i} }[X_{\text{guard} }]\right\}.$$

此时 $\theta_*$ 表示 Agent 产生的**安全改进的数量**。若把 $c_i$ 除以被采纳改动的数量，则改为瞄准"被采纳改动中属于安全改进的**比例**"。

一个类似的例子是科学 Agent：它能提出假设、通过数据收集探索假设、并宣布发现。假设本身以及 Agent 如何调查它们，都可以在轨迹上完全动态地演化。此时 $\theta_*$ 可以评估**真实假设或真实发现的数量或比例**。

#### 2.1 数据生成过程

作为真实世界评估的定义性特征，正确性标签 $(\theta_1,\dots,\theta_M)$ 与目标 $\theta_*$ 都是**未观测的**。为评估每个决策的正确性，我们考虑这样的设定：对每个 $i\in[M]$，我们观测到一个非负输出的随机序列 $\mathbf{e}_i=(e_{i,t},\bar{e}_{i,t})_{t\in\mathbb{N} }$，以及二元观测指示 $\mathbf{R}_i=(R_{i,t})_{t\in\mathbb{N} }$。$R_{i,t}=1$ 表示改动 $i$ 的一对非负随机变量 $(e_{i,t},\bar{e}_{i,t})$ 在时刻 $t$ 被观测到。对任意满足 $i>M$、$t>N$ 或 $R_{i,t}=0$ 的 $(i,t)$，我们定义 $(e_{i,t},\bar{e}_{i,t})=(1,1)$，并在 $i>M$ 或 $t>N$ 时令 $R_{i,t}=0$。我们定义观测信息上的滤子（filtration）为

$$\mathcal{F}_t=\sigma\left(\left\{R_{i,j}e_{i,j},R_{i,j}\bar{e}_{i,j}\right\}_{(i,j)\in\mathbb{N}\times[t]},\left\{R_{i,j}\right\}_{(i,j)\in\mathbb{N}\times[t+1]},\left\{\mathbf{1}[j\le N]\right\}_{j\in[t+1]}\right),$$

其中 $\mathcal{F}_t$ 表示由截至时刻 $t$ 观测到的 e 变量所诱导的 $\sigma$ 域，观测指示 $R_{i,j}$ 与延续指示 $\mathbf{1}[j\le N]$ 到时刻 $t+1$ 已知。这个滤子编码的是"时刻 $t+1$ 的 e 值生成之前"的信息，但时刻 $t+1$ 的**可观测性与是否延续**是已知的。由 $\mathcal{F}_t$ 的定义，轨迹长度 $N$ 是一个适应于 $(\mathcal{F}_t)_{t\in\mathbb{N} }$ 的、可能随机的停时；决策数量

$$M=\max\{i:\exists t\le N\ \text{使得}\ R_{i,t}=1\}$$

也允许是随机的。我们令

$$\mathcal{F}_N=\{A\in\mathcal{F}_\infty: A\cap\{N=t\}\in\mathcal{F}_t\ \ \forall t\ge 0\}$$

表示对应于最终观测输出的 $\sigma$ 域，其中 $\mathcal{F}_\infty=\sigma(\cup_{t=1}^{\infty}\mathcal{F}_t)$。记观测到的轨迹为

$$F_N=\left(M,N,(\mathbf{e}_i,\mathbf{R}_i)_{i=1}^{M}\right),$$

并令 $\mathcal{F}_N=\sigma(F_N)$。我们的数据驱动权重被形式化地定义为 $c_i=c_i(F_N)$，且当 $i>M$ 时 $c_i=0$。

令 $\mathcal{Q}$ 为轨迹与正确性标签变量 $(F_N,(\theta_i)_{i=1}^{M})$ 的所有联合分布 $Q$ 的类，且满足以下四个假设。

**假设 1（改动数量的期望有限）。** 改动/决策数量 $M$ 满足 $\mathbb{E}_Q[M]<\infty$，且 $M\ge 1$ 在 $Q$ 下几乎必然成立。

**假设 2（轨迹长度有限）。** $N$ 在 $Q$ 下几乎必然有限。

**假设 3（e 值约束）。** 对 $(e_{i,t},\bar{e}_{i,t})$ 在 $Q$ 下几乎必然非负。此外，$(1+e_{i,t}+\bar{e}_{i,t})$ 的累积和的期望有限，即

$$\mathbb{E}_Q\left[\sum_{i=1}^{M}\sum_{t=1}^{N}R_{i,t}(1+e_{i,t}+\bar{e}_{i,t})\right]<\infty,$$

且其条件期望满足 $\mathcal{F}_{t-1}$-条件 e 值约束

$$\mathbb{E}_Q\left[\theta_i R_{i,t}(e_{i,t}-1)\mid\mathcal{F}_{t-1}\right]\le 0,\qquad \mathbb{E}_Q\left[(1-\theta_i)R_{i,t}(\bar{e}_{i,t}-1)\mid\mathcal{F}_{t-1}\right]\le 0.$$

**假设 4（权重非负且期望有限）。** 目标权重 $c_i$ 对 $i\in[M]$ 在 $Q$ 下几乎必然满足 $c_i\ge 0$，且 $\mathbb{E}_Q\left[\sum_{i=1}^{M}c_i\right]<\infty$。

对 $Q\in\mathcal{Q}$，记 $\tilde{Q}$ 为其**仅关于观测轨迹 $F_N$** 的边缘分布，并令 $\tilde{\mathcal{Q} }=\{\tilde{Q}:Q\in\mathcal{Q}\}$ 为所有此类边缘分布的集合。

假设 3 的第二个条件说明：$(e_{i,t},\bar{e}_{i,t})$ 分别是假设 $\theta_i=1$ 与 $\theta_i=0$ 的 $\mathcal{F}_{t-1}$-条件 e 值（Vovk and Wang 2021）。期望里含有 $\theta_i$，是因为 $\theta_i$ 是由 Agent 动作生成的随机标签。

**例 2（二元目标指标下的 e 值）。** 考虑例 1，取 $X_{\text{goal} }\in\{0,1\}$ 且 $\theta_i=\mathbf{1}\{\mathbb{E}_{P_i}[X_{\text{goal} }]\ge\mathbb{E}_{P_{j_i} }[X_{\text{goal} }]\}$。固定 $0<b<a<1$ 并令 $r=(a+b)/2$。在决策 $i$ 的每个评估时刻 $t$，从 $P_i$ 观测一个新抽样 $X_{\text{goal},t}$，从 $P_{j_i}$ 观测一个 $X'_{\text{goal},t}$，二者在给定过去下独立。令 e 值为似然比

$$e_{i,t}=\frac{\ell_t(b,a)}{\ell_t(r,r)},\qquad \bar{e}_{i,t}=\frac{\ell_t(a,b)}{\ell_t(r,r)},\qquad \text{其中}\quad \ell_t(u,v)=u^{X_{\text{goal},t} }(1-u)^{1-X_{\text{goal},t} }\,v^{X'_{\text{goal},t} }(1-v)^{1-X'_{\text{goal},t} }.$$

第一个在 $\theta_i=1$ 时条件期望至多为 1，第二个在 $\theta_i=0$ 时条件期望至多为 1。因此，**大的 $e_{i,t}$ 是反对正确性的证据，大的 $\bar{e}_{i,t}$ 是支持正确性的证据**。这些似然比在连续评估中的**乘积**会累积证据。

#### 2.2 对 Agent 质量的估计与推断

我们构造上界与下界估计量的类，它们在**所有分布 $Q\in\mathcal{Q}$ 上一致地**在期望意义下界定 $\theta_*$。之所以选择"在期望意义下界定 $\theta_*$"，是因为两个具有相同边缘分布 $\tilde{Q}$ 的分布 $Q$ 与 $Q'$ 可能给出不同的 $\theta_*$ 期望值。具体而言，本文旨在刻画这样一类上下界估计量：它们**对所有数据生成过程 $Q\in\mathcal{Q}$ 提供一致保证**。

**定义 1（一致有效的界估计量）。** 令 $\widehat{\Theta}_N$ 表示所有 $\mathcal{F}_N$-可测、且对所有 $Q\in\mathcal{Q}$ 期望有限的实值函数之集合。若函数 $\hat{\theta}_U\in\widehat{\Theta}_N$ 满足

$$\inf_{Q\in\mathcal{Q} }\mathbb{E}_Q\left[\hat{\theta}_U-\theta_*\right]\ge 0,$$

则称其为一致有效的上界估计量。一致有效的下界估计量以相反的不等号类似定义。我们还构造在 $Q\in\mathcal{Q}$ 上一致的置信集。

**定义 2（一致有效的置信集）。** 令 $\mathcal{C}_N$ 表示从固定的覆盖误差参数 $\alpha\in(0,1)$ 与 $F_N$ 到实轴上集合的映射之类。若映射 $C(\alpha,F_N)$ 满足

$$\sup_{Q\in\mathcal{Q} }P_Q\left(\theta_*\not\in C(\alpha,F_N)\right)\le\alpha,$$

则称其为 $\theta_*$ 的一致 $(1-\alpha)$ 置信集。

**一致有效性**意味着：我们的估计量与置信区间在**所有** $Q\in\mathcal{Q}$ 上同时提供期望意义与概率意义下的有效保证，从而对任意 Agent 决策序列都能给出统计上严谨的质量评估。

### 3 Agent 质量的估计界

我们先给出 $\theta_*$ 上界估计量的类，它把观测到的 e 值对与**可预测权重**（predictable weights）结合起来构造上界估计。下界估计量类的类似结果见附录 "Lower Bound Estimation"。

为构造上界估计量，我们从**假设特定**的项出发，它们的期望上界了正确性参数 $\theta_i$。对 $i\in[M]$，定义

$$A_i=\sum_{t=1}^{N}w_{i,t}R_{i,t}(e_{i,t}-1),\qquad \bar{A}_i=\sum_{t=1}^{N}\bar{w}_{i,t}R_{i,t}(\bar{e}_{i,t}-1),$$

其中 $w_{i,t}$ 与 $\bar{w}_{i,t}$ 表示非负的 $\mathcal{F}_{t-1}$-可测权重。在条件于 $\theta_i=1$ 时，项 $A_i$ 沿评估轨迹具有**非正的**期望。因此，$A_i$ 的期望取正值只可能在 $\theta_i=0$ 时发生，$A_i$ 的较大取值构成"$\theta_i=0$"的证据。同理，$\bar{A}_i$ 的较大取值构成"$\theta_i=1$"的证据。我们用 $\psi_i$ 把关于正确性标签 $\theta_i$ 的证据与 $\mathcal{F}_N$-可测权重 $c_i$ 结合起来：

$$\psi_i=\max(c_i-A_i,\ -\bar{A}_i).$$

项 $\psi_i$ 对应于 $c_i\theta_i$ 的一个**向上偏**的估计。条件于 $\theta_i=1$ 时，$c_i-A_i$ 的期望至少为 $\mathbb{E}_{\tilde{Q} }[c_i]$；条件于 $\theta_i=0$ 时，$-\bar{A}_i$ 的期望非负。因此，$\psi_i$ 的期望至少为 $\mathbb{E}_{\tilde{Q} }[c_i\theta_i]$。我们的估计量定义为 $\psi_i$ 在 $M$ 个 Agent 决策上的求和：

$$\hat{\theta}_*^{U}=\sum_{i=1}^{M}\psi_i.$$

我们把形如式 (7) 的所有估计量（其可预测权重序列满足下列条件）定义为我们研究的估计量类。

**假设 5（可积的可预测权重）。** 对任意 $Q\in\mathcal{Q}$，权重 $(w_{i,t},\bar{w}_{i,t})$ 非负、$\mathcal{F}_{t-1}$-可测，且当 $R_{i,t}=0$ 时取零。此外，权重和的期望

$$\mathbb{E}_Q\left[\sum_{i=1}^{M}\sum_{t=1}^{N}R_{i,t}(w_{i,t}+\bar{w}_{i,t})\right]$$

对所有 $Q\in\mathcal{Q}$ 有限。

特别地，假设 5 对权重施加了可积性条件，以保证 $\mathbb{E}_Q\left[\hat{\theta}_*^{U}\right]$ 良定义。对任何满足假设 5 的权重选择，定理 1 表明我们的估计量在**所有** $Q\in\mathcal{Q}$ 上满足一致有效性。

**定理 1（一致有效的估计量）。** 设假设 1–4 成立。对任何满足假设 5 的权重序列 $(w_{i,t},\bar{w}_{i,t})$，$\hat{\theta}_*^{U}$ 满足定义 1。

> **人话解释**：无论 Agent 的轨迹分布长什么样（决策多依赖、什么时候停、权重怎么定），只要每个决策的 e 值按假设 3 的方式"不会在正确时膨胀"，把它们按 $\max(c_i-A_i,-\bar{A}_i)$ 拼起来再加总，得到的数在平均意义上**不会低估**真实质量 $\theta_*$。这就是"上界"的全部含义——不是逐条轨迹成立，而是在**任意 $Q$** 上一致地成立。

#### 3.1 逐实例锐度

一致有效性并不能保证程序**有信息量**：例如 $\sum_{i=1}^{M}c_i$ 本身就是一个一致有效的上界估计量（它显然总是 $\ge\theta_*$）。一个自然的性能度量是它的期望相对于 $\tilde{Q}$（观测输出的分布）的**锐度**。令 $\Pi(\tilde{Q})\subseteq\mathcal{Q}$ 表示所有在观测输出 $F_N$ 上边缘分布为 $\tilde{Q}$ 的 Agent 轨迹分布 $Q$ 之集合。若估计量 $\hat{\theta}^{U}$ 的期望等于 $\theta_*$ 在 $\Pi(\tilde{Q})$ 上的**最大可能期望值**，则称它是 $\tilde{Q}$-**锐**的上界：

$$\mathbb{E}_{\tilde{Q} }\left[\hat{\theta}^{U}\right]=U(\tilde{Q}),\qquad U(\tilde{Q})=\sup_{Q\in\Pi(\tilde{Q})}\mathbb{E}_Q[\theta_*].$$

下面我们证明：存在一列可预测权重，使我们的估计量 $\hat{\theta}_*^{U}$ 的期望**任意接近**于 $\tilde{Q}$-锐上界。

**定理 2（在可观测分布上的锐度）。** 设 $U(\tilde{Q})$ 如式 (8)。则对任意 $\tilde{Q}\in\tilde{\mathcal{Q} }$ 与 $\epsilon>0$，存在满足假设 5 的权重序列 $(w_{i,t},\bar{w}_{i,t})$，使得 $\hat{\theta}_*^{U}$ 满足

$$\mathbb{E}_{\tilde{Q} }\left[\hat{\theta}_*^{U}\right]\le U(\tilde{Q})+\epsilon.$$

> **人话解释**：定理 2 说，对任意 $\tilde{Q}\in\tilde{\mathcal{Q} }$，我们的估计量类都能任意接近锐界 $U(\tilde{Q})$。与定理 1 合起来看，结论是：**一致有效性不必以牺牲逐实例锐度为代价**——由定理 2 定义的那个"任意锐"的估计量本身就住在这个类里，因此它同时满足一致有效性。这一点很重要：它排除了"为了保证覆盖而把区间放到无信息"的退化解。

#### 3.2 与 Storey 估计量的比较

为把我们的方法与既有的有效上界估计方法对比，我们考虑经典 Storey 估计量（Storey 2002）的一个改编版本——它基于 p 值而不是 e 值。Storey 估计量 $\pi_m^{\text{Storey} }(\lambda)$ 由下式给出：

$$\pi^{\text{Storey} }(\lambda)=\left(\frac{\sum_{i=1}^{M}\mathbf{1}\left[p_i\ge\lambda\right]}{M(1-\lambda)}\right),$$

它对应于超均匀（super-uniform）p 值下"正确假设比例"的期望上界。参数 $\lambda\in[0,1)$ 需事先指定。为与既有结果比较，我们聚焦于 $M$ 固定、且对每个 $i\in[M]$ 只观测**单个** e 值 $e_i$ 的设定，目标为估计 $\theta_*=\frac{1}{M}\sum_{i=1}^{M}\theta_i$。在固定 $M$ 的设定下，可以先把 e 值转成 p 值，再套用 Storey 估计量，从而得到一个上界估计量。首先，由 Ramdas et al. (2023b)，用占优的 e 到 p 转换 $p_i=\min(1,1/e_i)$ 把 e 值 $(e_1,\dots,e_M)$ 转成 p 值；于是 Storey 估计量给出

$$\pi^{\text{Storey} }(\lambda)=\left(\frac{\sum_{i=1}^{M}\mathbf{1}\left[e_i\le 1/\lambda\right]}{M(1-\lambda)}\right).$$

在这个简化设定下，经过 e 到 p 转换的 Storey 估计量的期望**大于** $\theta_*$，因而构成有效的上界估计量。我们证明：对任意 $\lambda\in(0,1)$ 的选择，都存在我们估计量 $\hat{\theta}_*^{U}$ 的一个权重选择，使其估计出的上界在**逐路径**意义上不大于 Storey 估计量。

**引理 1（正确性比例上的占优选择）。** 固定 $\lambda\in(0,1)$，$M$ 固定，且对每个 $i\in[M]$ 只有单个 e 值 $(e_i)_{i=1}^{M}$。令对所有 $i\in M$ 取 $\bar{w}_i=0$，于是

$$\hat{\theta}_*^{U}=\sum_{i=1}^{M}\max\left(\frac{1}{M}-w_i(e_i-1),\ 0\right).$$

则取 $w_i=\frac{\lambda}{M(1-\lambda)}$ 可得：对 e 值 $(e_1,\dots,e_M)$ 的**任意**实现，都有 $\hat{\theta}_*^{U}\le\pi^{\text{Storey} }(\lambda)$。

> **人话解释**：在 e 值设定下，Storey 方法的常规改编**总是被**我们估计量类中一个带简单固定权重的成员所**占优**（即给出更紧的上界）。这不是渐近陈述，而是逐路径的逐点不等式。

**注 1（在实践中使用引理 1）。** 为在更一般的设定下利用引理 1 的结果，可以按 Vovk and Wang (2024a) 的鞅合并函数（式 (18)）合并序列 $(e_{i,t},\bar{e}_{i,t})_{t\in\mathbb{N} }$，得到单对 e 值 $(e_i,\bar{e}_i)$。例如取 $\lambda_{i,t}=1$ 时，$(e_i,\bar{e}_i)$ 对应于

$$e_i=\prod_{t\in[N]:R_{i,t}=1}e_{i,t},\qquad \bar{e}_i=\prod_{t\in[N]:R_{i,t}=1}\bar{e}_{i,t},$$

即**乘积 e 变量**。再令 $w_i=\lambda/(M(1-\lambda))$、$\bar{w}_i=0$，则我们的最终估计量**不劣于**"先做 e 到 p 转换、再套用 Storey 估计量"的做法。

### 4 Agent 质量的置信集

我们的置信集在估计框架之上，把项 $(A_i,\bar{A}_i)$ 用作**证据度量**。令 $\mathcal{A}_t=\{i:R_{i,t}=1\}$ 表示在时刻 $t$ 有证据被观测到的改动集合，并把证据项的**running 版本**记为 $A_{i,t}$ 与 $\bar{A}_{i,t}$：

$$A_{i,t}=\sum_{j=1}^{t}w_{i,j}R_{i,j}(e_{i,j}-1),\qquad \bar{A}_{i,t}=\sum_{j=1}^{t}\bar{w}_{i,j}R_{i,j}(\bar{e}_{i,j}-1),$$

并取 $A_{i,0}=\bar{A}_{i,0}=0$。对候选标签向量 $v\in\{0,1\}^{M}$，定义**候选资金**（candidate wealth）

$$K_t(\vartheta)=1+\sum_{i=1}^{M}\left(\vartheta_i A_{i,t}+(1-\vartheta_i)\bar{A}_{i,t}\right).$$

当 $\vartheta=(\theta_1,\dots,\theta_M)$ 时，由假设 3，$K_t(\vartheta)$ 的每个增量都具有非正的 $\mathcal{F}_{t-1}$-条件期望，因此 $K_t(\theta)$ 从资金 1 出发并**向下漂移**。于是，$K_t(v)$ 的较大取值就是反对向量 $v=(\theta_1,\dots,\theta_M)$ 的证据。我们的置信集 $C(\alpha,F_N)$ 取为所有"资金小于 $1/\alpha$"的标签向量的**投影**：

$$C(\alpha,F_N)=\left\{\sum_{i=1}^{M}c_i v_i:\ v\in V(\alpha,F_N)\right\},\qquad V(\alpha,F_N)=\left\{v\in\{0,1\}^{M}:\ K_N(v)<\frac{1}{\alpha}\right\}.$$

若 $K_N(v)$ 非负，则由假设 3，它构成 $(\theta_1,\dots,\theta_M)=\vartheta$ 的一个合法 e 值。我们的置信集就对应于**所有未被拒绝的向量 $v$ 的集合**。我们对可预测权重序列施加限制，以保证 $K_N(v)$ 对**所有** $v\in\{0,1\}^{M}$ 在 $Q\in\mathcal{Q}$ 上一致地是合法 e 值。$C(\alpha,F_N)$ 的最大与最小元素，是在二元 $v$ 上、受单一线性约束 $K_N(v)<1/\alpha$ 最大化/最小化线性目标 $\sum_i c_i v_i$ 的解——这是一个 **0–1 背包问题**。当系数相等（$c_i=c$）时，无需调用求解器。

#### 4.1 共享资金的序贯下注

为刻画可预测权重的限制，我们先把 $K_t(\vartheta)$ 参数化为

$$K_t(\vartheta)=B_t+\sum_{i=1}^{M}\left(\vartheta_i D_{i,t}+(1-\vartheta_i)\bar{D}_{i,t}\right),$$

$$B_t=1+\sum_{i=1}^{M}\min\{A_{i,t},\bar{A}_{i,t}\},\quad D_{i,t}=(A_{i,t}-\bar{A}_{i,t})_+,\quad \bar{D}_{i,t}=(\bar{A}_{i,t}-A_{i,t})_+.$$

$B_t$ 表示**每个**候选向量 $\vartheta\in\{0,1\}^{M}$ 共享的资金，而 $D_{i,t}$ 与 $\bar{D}_{i,t}$ 分别表示反对 $\theta_i=1$ 与反对 $\theta_i=0$ 的**超额证据**。于是 $K_t(\vartheta)$ 等于公共资金池 $B_t$ 加上 $\bar{\theta}$ 所下注一侧的超额证据。我们的推断程序类对权重 $(w_{i,t},\bar{w}_{i,t})$ 施加如下限制。

**假设 6（共享资金的序贯下注）。** 对每个 $t\in\mathbb{N}$、$Q\in\mathcal{Q}$，权重 $w_{i,t}$ 与 $\bar{w}_{i,t}$ 可表示为 $w_{i,t}=\lambda_{i,t}(D_{i,t-1}+b_{i,t})$ 与 $\bar{w}_{i,t}=\bar{\lambda}_{i,t}(\bar{D}_{i,t-1}+b_{i,t})$，其中（i）下注比例 $\lambda_{i,t},\bar{\lambda}_{i,t}\in[0,1]$ 与转移 $b_{i,t}\ge 0$ 都是 $\mathcal{F}_{t-1}$-可测的；（ii）当 $R_{i,t}=0$ 时，取 $b_{i,t}=0$ 且 $\lambda_{i,t}=\bar{\lambda}_{i,t}=0$；（iii）转移 $b_{i,t}$ 满足预算约束 $\sum_{i\in\mathcal{A}_t}b_{i,t}\le B_{t-1}$ 在 $Q$ 下几乎必然成立。

假设 6 用下注比例 $(\lambda_{i,t},\bar{\lambda}_{i,t})$ 与资金转移参数 $b_{i,t}$ 来参数化权重 $(w_{i,t},\bar{w}_{i,t})$。由预算约束 $\sum_{i\in\mathcal{A}_t}b_{i,t}\le B_{t-1}$ 可知，$K_t(v)$ 对所有 $t\in\mathbb{N}$ 非负。转移参数 $b_{i,t}$ 表示从资金 $B_{t-1}$ 中**分配给检验 $\theta_i$ 取值**的金额；$b_{i,t}$ 越大，可分配的资金越多，这体现在 $(w_{i,t},\bar{w}_{i,t})$ 的上界上。因此，向检验 $\theta_i$ 转移的资金越大，在我们构造中对应的权重上界也越大。比例 $(\lambda_{i,t},\bar{\lambda}_{i,t})$ 是博弈鞅（game martingale，Vovk and Wang 2024a）中通常意义的下注比例，决定相对于假设特定预算 $D_{i,t-1}+b_{i,t}$ 与 $\bar{D}_{i,t-1}+b_{i,t}$，分别投入多少资本去收集反对 $\theta_i=1$ 与反对 $\theta_i=0$ 的证据。

**回收 e 值合并。** 令 $(E_{i,N},\bar{E}_{i,N})$ 表示对 $\theta_i=1$ 与 $\theta_i=0$、用 Vovk and Wang (2024a) 的博弈鞅合并后的 e 值：

$$E_{i,N}=\prod_{j\le t:R_{i,j}=1}\left(1+\lambda_{i,j}(e_{i,j}-1)\right),\qquad \bar{E}_{i,t}=\prod_{j\le t:R_{i,j}=1}\left(1+\bar{\lambda}_{i,j}(\bar{e}_{i,j}-1)\right).$$

由假设 3，鞅合并给出对 $\theta_i=1$ 与 $\theta_i=0$ 合法的 e 值 $E_{i,N}$ 与 $\bar{E}_{i,N}$。对一个固定的非负向量 $b\in\mathbb{R}^{M+1}$ 且 $\sum_{i=0}^{M}b_i=1$，任意依赖假设下的**加权平均合并**（Wang 2025）给出 $(\theta_1,\dots,\theta_M)=v$ 的 e 值：

$$K_N(\vartheta)=b_0+\sum_{i=1}^{M}b_i\left(\vartheta_i E_{i,N}+(1-\vartheta_i)\bar{E}_{i,N}\right).$$

按上述方式取 $(\lambda_{i,j},\bar{\lambda}_{i,j})$，并在 $t=1$ 取 $b_{i,1}=b_i$、令 $b_{i,t}=b_{i,1}\min(E_{i,t-1},\bar{E}_{i,t-1})$，即可**回收**这一构造。注意假设 6 允许更一般的构造：$(b_{i,t})$ 可以在满足预算约束的公共资金池 $B_t-B_{t-1}$ 中任意分配。

**随机假设标签下的限制。** 与典型置信集相比，假设 6 需要额外一条限制：由于权重 $(w_{i,t},\bar{w}_{i,t})$ 与资金池 $B_t$ 在**所有** $v\in\{0,1\}^{M}$ 之间共享，每个满足 $\vartheta_i=1$ 的 $\vartheta\in\{0,1\}^{M}$ 在 $K_t(\vartheta)$ 中都含**同一项** $A_{i,t}$，每个满足 $\vartheta_i=0$ 的 $\vartheta$ 也都含**同一项** $\bar{A}_{i,t}$。相反，当 $\theta_i$ 固定时，每个标签向量 $\vartheta$ 都可以有自己**假设特定**的权重 $(w_{i,t}^{\vartheta},\bar{w}_{i,t}^{\vartheta})$、资金 $B_t^{\vartheta}$ 与转移 $b_{i,t}^{\vartheta}$。只要选取 e 值与标签 $\theta_i$ 之间存在依赖的 $Q$，就能说明假设特定的调参方式是**失败**的。

**例 3（对误报做出反应的 Agent）。** 令 $\alpha=1/10$、$M=2$、$N=1$、$c_1=c_2=1$、$\bar{e}_1=\bar{e}_2=1$。首先，Agent 上线一个正确改动 $\theta_1=1$，以概率 $1/10$ 出现 $e_1=10$（一次误报），否则 $e_1=0$。在出现误报 $(e_1=10)$ 之后，它上线一个**坏的**修复 $(\theta_2=0)$；否则它上线一个好的改动 $(\theta_2=1)$。改动 2 自身的实验在 $\theta_2=0$ 时给出 $e_2=20$，在 $\theta_2=1$ 时以概率 $1/20$ 给出 $e_2=20$、否则 $e_2=0$。两个 e 值都满足假设 3。若对每个 $v$ 分别取权重，则

$$K_N(1,1)=(e_1+e_2)/2,\quad K_N(1,0)=e_1,\quad K_N(0,1)=e_2,\quad K_N(0,0)=1.$$

在该轨迹分布下，**分离权重**未能覆盖 $\theta_*$ 的概率为 $0.145>\alpha$；而取**共享权重** $w_{i,1}=\bar{w}_{i,1}=1/2$（$i\in[M]$）时，未能覆盖 $\theta_*$ 的概率为 $0.045<\alpha$。

> **人话解释**：这个反例说明，如果允许每个候选标签向量各调一套权重，覆盖率会**崩掉**（0.145 > 0.1）。原因正是 Agent 会"对误报做出反应"——标签与证据之间存在依赖。共享同一份资金池的下注方式（0.045 < 0.1）才保住了名义覆盖率。

#### 4.2 在 Agent 轨迹上的一致覆盖

在第 2 节的正则条件与假设 6 的序贯下注限制下，我们得到定理 3 给出的一致覆盖保证。

**定理 3（一致置信集）。** 固定 $\alpha\in(0,1)$，并设假设 1–4 成立。对任何满足假设 6 的权重序列 $(w_{i,t},\bar{w}_{i,t})$，式 (15) 中的置信集 $C(\alpha,F_N)$ 是一个一致有效的 $(1-\alpha)$ 置信集（定义 2）。

> **人话解释**：定理 3 与定理 1 的差别在于"覆盖"而非"期望"：$\theta_*$ 落在 $C(\alpha,F_N)$ 之外的概率被 $\alpha$ 控制住，而且这个控制**对任意轨迹分布一致成立**——包括 Agent 会因证据而提前停止、改动数量随机的情形。

### 5 案例：比较编码 Agent

在真实世界案例研究中，我们比较两个大语言模型在 NetworkX Python 库（Hagberg et al. 2008）上生成代码加速的性能。

**设置。** 我们评估 Claude Opus 5 与 Claude Haiku 4.5，均以 **high effort** 运行，要求它们对 NetworkX 包提出**至多 50 个局部化的运行时优化**。两个 Agent 分别独立运行。改动是在该 Agent 此前已被接受的改动所留下的代码树上**序贯**提出的。沿每个 Agent 的轨迹，若第 $i$ 个改动使**几何平均运行时**相对上一个改动下降至少 $p\%$，则该改动被视为正确。我们取 $c_i=1/M$。

**随机停时与 e 值。** 对每个 Agent，其第 $i$ 个改动记录在 $N_i$ 个生成图上的对比量 $(Y_{i,1},\ldots,Y_{i,N_i})$，其中 $Y_{i,t}$ 是改动 $i$ 的对数运行时减去改动 $i-1$ 的对数运行时。评估所用的图使用两个 Agent 都无法获得的随机种子，对应于未知的用户输入分布。对最小加速 $p\%$，取 $\delta_p=-\log(1-p/100)$，并对平移后的对比量 $X_{i,t}=Y_{i,t}+\delta_p$ 应用附录 8.1 的单边右 Haar 构造。这产生 $E_{i,t}$ 与 $\bar{E}_{i,t}$，其增量对为 $e_{i,t}=E_{i,t}/E_{i,t-1}$ 与 $\bar{e}_{i,t}=\bar{E}_{i,t}/\bar{E}_{i,t-1}$，分别提供反对 $\theta_i=1$ 与反对 $\theta_i=0$ 的证据。样本量 $N_i$ 是**自适应确定**的：前 10 对之后，每增加 5 对评估一次是否停止；当 $E_{i,t}$ 或 $\bar{E}_{i,t}$ 任一达到 **100**，或已观测 **150 对**时停止采样。

**可预测调参。** 在所有实验中，我们使用一个**可预测**的调参启发式：在每个时刻 $t$ 基于轨迹模拟选择权重 $(w_{i,t},\bar{w}_{i,t})$。对估计量，我们的目标是**最小化与最大化**上下界估计量的条件期望；对推断，我们同样最小化期望宽度的凸上界。两种方法都在每个时刻 $t$ 利用 **64 次轨迹模拟**来近似各 $t\in\mathbb{N}$ 处的条件期望，从而得到权重 $(w_{i,t},\bar{w}_{i,t})$。该方法及其伪代码见附录 7。

#### 5.1 结果讨论

> **图 1：NetworkX 实验的估计界与置信区间。** 置信集是对每个最小加速阈值与每个 Agent 逐点给出的，取 $\alpha=0.1$。加粗线表示我们估计的界与置信集的中点。

在图 1 中，我们把估计的上/下界估计量与置信集画成 $p$（一个改动被视为正确所要求的最小加速阈值）的函数。**在所有阈值上，Opus 估计出的正确改动比例都高于 Haiku。** 例如在最小加速 **5%** 处，Opus 的下界估计约为 **0.15**，而 Haiku 的上界估计为 **0.11**。随最小加速阈值提高，这一差距**持续存在**，说明 Opus 产生的运行时改进比 Haiku 更有实质意义。

我们的置信集还提供了关于这些结论**可靠性**的额外信息。尽管样本量是自适应确定的、且相邻代码改动之间存在依赖，我们的程序在考察的各个加速阈值上都给出了**有信息量的 90% 逐点置信集**。特别地，即使要求 **10%** 的加速，下置信集仍保持为正——这提供了统计证据，说明两个 Agent 产生有意义改进的比例都**非零**。

本案例研究表明：**在没有标准答案正确性标签的任务上，Agent 质量仍然可以被有意义地评估，同时保留严格的统计保证**。在我们的实验中，每个代码改动的真实几何平均运行时改进是未知的，证据是自适应收集并自适应停止的。我们的框架把这种序贯证据转化为对**用户自定义的 Agent 质量概念**（例如有益决策的比例）的可解释估计与置信界。对在多个 Agent 之间做选择的实践者而言，"正确改动比例"这类指标使人能够按**实际有意义改进出现的频率**来比较，而不是按基准分数或带噪声的经验正确性标签来比较。此外，正确性的门槛（例如最小改进幅度）可以按部署优先级来选取，从而让实践者**按运营意义来定义正确**。

### 6 结论

随着 AI Agent 越来越多地在真实系统中做出有后果的决策，评估其表现必须**超越静态基准或启发式的正确性标签**。我们提出了一个基于序贯 e 值的**零假设比例估计**框架来评估 Agent 质量，允许自适应决策、数据依赖停时，以及部署后才定义的质量度量。我们的结果确立了：在这些条件下，**一致有效的估计与推断是可能的**，且估计量可以逼近逐实例锐界。我们的编码 Agent 案例研究展示了该框架如何提供对 Agent 表现的可解释评估。

我们的工作开启了若干未来研究方向。我们的设定是**有意一般化**的，构造的是一致有效的估计界与置信集。虽然我们的方法在任意 Agent 轨迹分布上都确保了所需的统计保证，但在更强的假设下（例如独立同分布的 e 值对、固定的数据收集策略、或对 Agent 行为的限制），可能存在**更高效**的估计与推断程序。一个有意思的实践方向是开发更高效的调参流程，包括在假设之间与时间上分配证据的更好的可预测方法。最后，我们的实验**意在作为案例研究**，而非跨 Agent、跨任务、跨正确性目标的严格评估。由于我们的方法具有一致保证，将其用于跨已记录 Agent 轨迹的大规模评估，有望做到**基于过往表现、以统计上更有原则的方式、针对相关任务来选择 Agent**。

## 与路线图的挂接

- **E0-04（第一性原理：信度、效度、区分度）**：这篇是把"效度"问题**推到极限**的一次演练。传统评测里，效度问的是"我的测量是否测到了想测的能力"；这里连"能力有没有发生"都无法直接观测，只能靠 e 值提供的**带方向的证据**去界定。它给出的正是"没有金标准时，效度论证该长什么样"：不是拿一个标签去对，而是构造一个在**所有可能的数据生成过程**上都成立的界。读它的时候请把定义 1、定义 2 抄下来——"一致有效"这四个字是后面一切讨论的地基，它明确区分了"在期望意义下上界"与"以 $1-\alpha$ 概率覆盖"两种保证。
- **E3-02（区间估计）**：这篇是"区间"而不是"点估计"的教科书级范例，且它踩中了 E3-02 最痛的点：**样本不独立**。Agent 的第 $i$ 个决策是在第 $i-1$ 个决策的结果上做出的，轨迹还会因为"证据够了"而提前停止——这正是标准误按任务聚类、以及任何依赖独立同分布假设的区间都会失效的场景。作者的解法不是修正方差，而是换成 e 值 + 鞅下注：假设 3 的 $\mathcal{F}_{t-1}$-条件约束保证了**可选停时下仍然有效**，假设 6 的预算约束（$\sum_{i\in\mathcal{A}_t}b_{i,t}\le B_{t-1}$）保证了资金非负。例 3 那个 $0.145$ 对 $0.045$ 的对比，就是"分离权重在依赖下崩掉、共享资金池兜住"的干净反例，值得当作 E3-02 的必读案例。
- **E3-06（部分成功与分级得分）**：$c_i$ 这个权重是本文最灵活也最容易被误用的地方。取 $c_i=1$ 得到"正确改动的**数量**"，取 $c_i=1/M$ 得到"**比例**"，而例 1 里 $c_i$ 还可以编码"这个改动**是否被采纳**"——于是 $\theta_*$ 从"改了多少"变成"**留下的**改了多少"。这正好对应 E3-06 的核心张力：把 0/1 拆成分级或加权，会引入新的偏差（分子分母都在变、权重可能依赖结果本身）。本文的处理是把 $c_i$ 明确定义成 $\mathcal{F}_N$-可测的**数据依赖权重**（假设 4 只要求非负与期望有限），并让一致性证明覆盖这种依赖——这是把"分级得分"纳入统计保证的正确姿势，而不是先算分再补一个区间。
