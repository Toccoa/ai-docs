## 从哪里读起

**想做 Agent 架构**，从 **[AI Agent 顶级架构师知识地图](<AI Agent 顶级架构师/00-知识地图>)** 进——先搞清楚"你在造的是个什么系统"，再谈框架与选型。

**第一次来**，也可以先读这两篇建立坐标系：

1. **[RAG 知识地图](<RAG 学习路线图/00-RAG知识地图>)** — 全局框架，RAG 的失败点分几层、每层怎么证伪
2. **[每日推荐索引](<RAG 学习路线图/04-索引>)** — 一行一期，按时间翻，看这条路线每天在读什么

之后按左侧目录挑：`AI Agent 顶级架构师`、`RAG 学习路线图`、`AI Agent 效果测评` 是三条成体系的课程线，`每日 AI Agent 技术精选` 是按天归档的情报流。

**想做 Agent 评测**，从 **[Agent 效果测评知识地图](<AI Agent 效果测评/00-知识地图>)** 进——先搞清楚"分数会在哪里骗你"，再学怎么造一个可信的分数。
